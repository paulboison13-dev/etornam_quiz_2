## Files
- `regression_comparison.ipynb`: analysis, model training, evaluation, actual-vs-predicted plot, residual analysis, and conclusion.
- `regression_data.csv`: 5,000-row synthetic dataset.
- `requirements.txt`: Python dependencies.

## Run in VS Code
1. Open this folder in VS Code.
2. In a terminal, create a virtual environment: `python -m venv .venv`
3. Activate it in PowerShell: `.\.venv\Scripts\Activate.ps1`
4. Install packages: `python -m pip install -r requirements.txt`
5. Open `regression_comparison.ipynb`, select the `.venv` Python kernel, and choose **Run All**.

The dataset is synthetic and created for educational use.
